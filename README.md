# 🧮 Advanced C Calculator

A menu-driven **Advanced Calculator** written in **C programming language**.
This project demonstrates the use of **functions, arrays, loops, switch-case, mathematical operations, and number-based problems**.

## ✨ Features

### Basic Operations

1. Addition using Array
2. Subtraction using Array
3. Multiplication using Array
4. Division
5. Modulus
6. Square
7. Power

### Mathematical Operations

8. Factorial
9. Fibonacci Series
10. Trigonometric Operations

* Sin
* Cos
* Tan

### More Operations

11. More

* Leap Year
* Palindrome Number
* Strong Number
* Armstrong Number
* Perfect Number
* Magic Number

12. Exit

## 🛠️ Concepts Used

* C Programming
* Functions
* Arrays
* `for` loop
* `while` loop
* `switch-case`
* `if-else`
* User input using `scanf()`
* Output using `printf()`
* Mathematical functions
* `math.h` library
* Number series and number checking

## ▶️ How to Run

### Using GCC

Compile the program:

```bash
gcc calculator.c -o calculator -lm
```

Run:

**Windows**

```bash
calculator.exe
```

**Linux / Termux**

```bash
./calculator
```

> `-lm` is used to link the mathematical library because the program uses functions such as `pow()`, `sin()`, `cos()`, and `tan()`.
